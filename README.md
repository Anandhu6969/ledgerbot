# 📊 Telegram Ledger Bot

A simple **Telegram bot** that helps manage ledgers within groups.  
The bot allows adding amounts, setting profit %, tracking repayments, and maintaining separate ledgers per Telegram group.  

---

## 🚀 Features
- Add an amount to the ledger with a profit %  
- Calculate repayment as `amount - profit`  
- Track **pending** and **repaid** amounts  
- Each Telegram group has its own independent ledger  
- Deployed on **Google Cloud Run** with **Firestore** as database  

---

## 🛠️ Tech Stack
- **Python**  
- **Google Cloud Run** (deployment)  
- **Firestore** (database)  
- **Telegram Bot API (BotFather)**  
- **Docker** (containerization)  
- **GitHub** (version control)
